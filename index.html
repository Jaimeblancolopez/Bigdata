Conceptos básicos (sin tecnicismos)

Base de datos
Colección organizada de información que evita duplicados y permite consultarla desde varias aplicaciones.
SGBD / DBMS
Software que administra los datos (MySQL en el servidor del taller). phpMyAdmin es la ventana web; cada participante tiene su propia base (cafenorte_XX).
Tabla
Como una hoja de Excel: filas = registros, columnas = campos (nombre, precio, fecha…).
Clave primaria
Identificador único de cada fila (ej. ClienteID = 1, 2, 3…).
Clave foránea
Conecta tablas: en Pedidos, ClienteID apunta a un cliente real en la tabla Clientes.
SQL
Lenguaje para hablar con la base de datos: crear, leer, actualizar y borrar datos.

Modelo del ejemplo: Café Norte

Clientes (1) ──────< (N) Pedidos (1) ──────< (N) DetallePedidos >────── (N) Productos (1) ClienteID PedidoID, ClienteID ProductoID, Cantidad Nombre, Teléfono Fecha, Total

Usar inteligencia artificial en el taller

Puedes usar ChatGPT, Copilot, Cursor o Gemini. La IA no sustituye entender el resultado: siempre revisa y ejecuta en un entorno de prueba.

Regla de oro: Describe el negocio en español, pide SQL para MySQL 8, y pide que explique cada parte en lenguaje simple.

Prompt 1 — Diseñar tablas desde cero

Soy principiante en bases de datos. Tengo una cafetería llamada "Café Norte" y necesito guardar clientes, productos y pedidos. Diseña un modelo con tablas relacionadas (claves primarias y foráneas) y genera el script CREATE TABLE para MySQL 8 (InnoDB, utf8mb4). Explica cada tabla en una frase simple en español. No uses sintaxis de SQL Server (sin GO, sin IDENTITY).

Prompt 2 — Generar datos de prueba

Ya tengo estas tablas en MySQL: Clientes, Productos, Pedidos, DetallePedidos (estructura Café Norte). Genera INSERT con al menos 3 clientes, 4 productos y 3 pedidos con su detalle. Solo MySQL 8, sin explicación larga.

Prompt 3 — Consulta en lenguaje natural

Tengo en MySQL la base cafenorte_[MI_CODIGO] con tablas Clientes, Productos, Pedidos y DetallePedidos. Escribe una consulta SQL que responda: "¿Cuáles son los dos productos más vendidos por cantidad total?" Usa LIMIT, no TOP. Incluye comentarios en español línea por línea.

Prompt 4 — Corregir un error

Ejecuté este SQL en MySQL (phpMyAdmin) y me dio error. Explica el error en español simple y dame el script corregido para MySQL 8: [PEGA AQUÍ TU SCRIPT Y EL MENSAJE ROJO DE PHPMYADMIN]

01 — Crear tu base de datos 
-- Tu base (XX = tu código al copiar desde la web)
CREATE DATABASE IF NOT EXISTS cafenorte_XX
  CHARACTER SET utf8mb4
  COLLATE utf8mb4_unicode_ci;

USE cafenorte_XX;
02 — Crear tablas (Clientes, Productos, Pedidos, DetallePedidos) 
USE cafenorte_XX;

CREATE TABLE Clientes (
    ClienteID      INT AUTO_INCREMENT PRIMARY KEY,
    Nombre         VARCHAR(80)  NOT NULL,
    Telefono       VARCHAR(20),
    Email          VARCHAR(100),
    FechaRegistro  DATE DEFAULT (CURDATE())
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

CREATE TABLE Productos (
    ProductoID     INT AUTO_INCREMENT PRIMARY KEY,
    Nombre         VARCHAR(80)  NOT NULL,
    Precio         DECIMAL(10,2) NOT NULL,
    Stock          INT NOT NULL DEFAULT 0
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

CREATE TABLE Pedidos (
    PedidoID       INT AUTO_INCREMENT PRIMARY KEY,
    ClienteID      INT NOT NULL,
    FechaPedido    DATETIME DEFAULT CURRENT_TIMESTAMP,
    Total          DECIMAL(10,2),
    FOREIGN KEY (ClienteID) REFERENCES Clientes(ClienteID)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

CREATE TABLE DetallePedidos (
    DetalleID      INT AUTO_INCREMENT PRIMARY KEY,
    PedidoID       INT NOT NULL,
    ProductoID     INT NOT NULL,
    Cantidad       INT NOT NULL,
    PrecioUnitario DECIMAL(10,2) NOT NULL,
    FOREIGN KEY (PedidoID) REFERENCES Pedidos(PedidoID),
    FOREIGN KEY (ProductoID) REFERENCES Productos(ProductoID)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
03 — Insertar datos de ejemplo 
USE cafenorte_XX;

INSERT INTO Clientes (Nombre, Telefono, Email) VALUES

INSERT INTO Productos (Nombre, Precio, Stock) VALUES

INSERT INTO Pedidos (ClienteID, Total) VALUES (1, 11000), (2, 6500);
04 — Consultas SELECT, JOIN, WHERE, LIKE, BETWEEN 
-- Todos los clientes
SELECT * FROM Clientes;

-- Productos caros
SELECT Nombre, Precio FROM Productos
WHERE Precio > 4000 ORDER BY Precio DESC;

-- Pedidos con nombre del cliente
SELECT p.PedidoID, c.Nombre, p.Total
FROM Pedidos p
INNER JOIN Clientes c ON p.ClienteID = c.ClienteID;
05 — MAX, MIN, AVG, COUNT, fechas, GROUP BY 
SELECT
    COUNT(*) AS TotalProductos,
    MAX(Precio) AS PrecioMaximo,
    AVG(Precio) AS PrecioPromedio
FROM Productos;

SELECT NOW() AS Ahora, YEAR(CURDATE()) AS Anio;

SELECT Nombre, Precio FROM Productos
ORDER BY Precio DESC LIMIT 2;

SELECT c.Nombre, COUNT(p.PedidoID) AS Pedidos
FROM Clientes c
LEFT JOIN Pedidos p ON c.ClienteID = p.ClienteID
GROUP BY c.Nombre;
